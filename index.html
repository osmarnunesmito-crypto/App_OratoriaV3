RITUAL DE 3 MINUTOS

Chegue ao presente antes de chegar ao palco.

Um aquecimento breve para desacelerar e organizar o foco. Faça de forma confortável, sem forçar a respiração ou a voz.

01 · Aterre-se (30 segundos)Sinta os pés no chão. Solte os ombros e perceba o ambiente ao redor.
02 · Respire com suavidade (60 segundos)Inspire confortavelmente e solte o ar um pouco mais devagar, sem prender nem forçar. Retome seu ritmo natural se sentir desconforto.
03 · Acorde a voz (45 segundos)Leia uma frase em volume confortável. Repita variando pausas e ênfase em palavras diferentes.
04 · Visualize o primeiro minuto (45 segundos)Imagine-se começando com calma, olhando para uma pessoa e comunicando sua ideia principal.

PRIVACIDADE E CONTROLE

Seus dados, suas regras.

Este app usa armazenamento local no navegador. Em uma versão publicada, os dados ficam vinculados ao domínio do aplicativo; para uso entre dispositivos será necessário adicionar uma conta e banco de dados na nuvem.

O que pode ser feito aqui
✓ Criar apresentações, notas, treinos e check-ins
✓ Editar qualquer registro criado pelo usuário
✓ Excluir um registro individual
✓ Exportar uma cópia dos dados
✓ Importar uma cópia
✓ Zerar todos os dados deste dispositivo

Antes de distribuir

Recomendação de produto

1. Dados de demonstraçãoO aplicativo deve iniciar sem apresentações, notas, histórico ou check-ins de usuários anteriores.
2. Identidade do usuárioO nome/perfil deve ser separado dos dados de cada pessoa.
3. ArmazenamentoUse localStorage apenas para a versão local/offline. Para sincronizar celular e desktop, use autenticação + banco de dados.
4. Limpeza segura“Excluir item” remove somente aquele registro; “Limpar todos os dados” exige confirmação explícita e pode pedir uma segunda confirmação.
